# Physics in Juvenile

A physics outreach session for young residents of a juvenile correctional facility, delivered by graduate students from NED University of Engineering & Technology and the University of Karachi. Topics: Particle Physics, Medical Physics, and Quantum Physics.

Inspired by Dr. Gediminas Sarpis's *Particle Physics in Prisons*: https://gedassarpis.substack.com/p/inscribed-hands-particle-physics

The site is a single static page (`index.html`) served with GitHub Pages.
